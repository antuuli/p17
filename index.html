      About this page. Unofficial planning page made by NuPS P17 team staff for our own season planning. It is not affiliated with Palloliitto or the tournament organizers, and details can change: always check the organizer's page before registering.

      Privacy. No cookies, analytics or tracking. Fonts are included in the page, so nothing is loaded from Google. The page is hosted on GitHub Pages, which keeps its own server logs. Only team names are shown, no player information.
